## 🎯 Descrição

Servidor em **Node.js** que fornece painel para líderes de guilda, controle de presença e persistência de dados de raides. O projeto cobre desde o back-end (API e lógica de servidor) até a interface web responsiva para os jogadores.

> 🐉 Foco em **World of Warcraft: Wrath of the Lich King (WotLK)** — gerenciamento de raides, tamanhos de grupo e participantes.

---

## ✨ Funcionalidades

| Status | Funcionalidade |
| :---: | :--- |
| ✅ | Servidor local/remoto para acesso ao sistema |
| ✅ | Cadastro e gerenciamento de jogadores |
| ✅ | Criação e edição de raides e tamanhos de grupo |
| ✅ | Painel exclusivo para líderes de evento |
| ✅ | Layout responsivo adaptado a telas diferentes |
| ✅ | Persistência de dados das atividades |

## ⚙️ Como Executar

### ✅ Pré-requisito
- 🟢 Ter o **Node.js** e o **npm** instalados

### Passo a passo

```bash
# 1. Clonar o repositório
git clone https://github.com/ILeekhan/guild-backend.git

# 2. Entrar na pasta
cd guild-backend

# 3. Instalar dependências
npm install

# 4. Iniciar o servidor
node server.js
```

### 🌐 Acesse no navegador
**`http://localhost:3000/`**

> ☁️ O deploy está pronto para plataformas como **Render**.
